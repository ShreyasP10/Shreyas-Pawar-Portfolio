## 🚀 Featured Projects

### [Chatrixz](https://github.com/ShreyasP10/Chatrixz)
A real-time encrypted chat application where every message is encrypted on the client with AES-256-GCM before upload. Built with React, Firebase, WebRTC, and PWA support.

### [Kepler-404](https://github.com/ShreyasP10/Kepler-404)
Full-stack prototype for the ISRO Space Applications Centre Hackathon. Features an AI-powered workflow that super-resolves Landsat 9 Thermal Infrared imagery from 200m to 100m using PyTorch, OpenCV, and Rasterio.

### [Camptel AI](https://github.com/ShreyasP10/Camptel-AI)
Campus decision-intelligence platform built for the Google Cloud Hackathon. Transforms raw campus data into actionable decisions using Gemini AI, Next.js, and NVIDIA RAPIDS for 11x GPU speedups.

### [CropIQ](https://github.com/ShreyasP10/CropIQ)
AI-powered crop disease detection platform with an Android app (Java + Kotlin), web portal, and admin dashboard. Uses a CNN implemented with TensorFlow Lite to detect diseases and provide solutions.
